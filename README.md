Team:
- Aman Rawat
- Abhishek Singh Chib

## Run
Open `index.html` in a browser. No server or installation is required.

## Demo functionality
- 50 sample medicine records, each listed by 4 demo vendors (200 vendor listings).
- Search by medicine name or generic name.
- Compare vendor prices and sample stock.
- Sort vendors by lowest price or nearest shop.
- View vendor addresses and open map search links.

## DSA used
1. Hash Map — normalized medicine/generic lookup.
2. Arrays — medicine records and vendor offers.
3. Sorting — price/distance ordering.
4. Graph concept — locations and vendor proximity as an extensible model.

## Important
This is a student demonstration prototype. All vendor names/addresses, prices, stock and distances are fictional sample data, not live pharmacy inventory. This is not medical advice. Prescription medicines should only be obtained and used under the guidance of a licensed healthcare professional.
