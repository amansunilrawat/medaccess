Team:

## Run
Open `index.html` in a browser. No server or installation is required.

## DSA used in this prototype
1. Hash Map — `medicineMap` gives fast exact medicine lookup.
2. Arrays — medicine/provider records and offers.
3. Sorting — offers are sorted by price before display.
4. Graph concept — the UI represents nearby provider relationships/location nodes; this can be extended to an actual adjacency-list graph in C++.

## Demo medicines
- Paracetamol
- Azithromycin
- Cetirizine
- Metformin

## Important
This is a student demonstration prototype using sample data. Availability, prices and provider information are not live pharmacy data.
